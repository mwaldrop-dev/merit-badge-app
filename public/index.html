About This Tool

This application is intended to be a resource for Scouts and Merit badge counselors to easily access the latest merit badge info and generate an up to date worksheet to capture some of the work. This does NOT replace Blue Cards and is NOT an official source for requirements. The Scouting America links will take you to official requirements and merit badge pamphlets.

The worksheets generated are straight forward and fairly simple, and are intended to simply help facilitate the interaction with the merit badge counselor.

NOTE: This is intended to be a substitute for the worksheets that lived at http://usscouts.org/mb/worksheets/list.asp. These sheets are no longer updated so do not match current requirements.
