Add a Merit Badge

Drag the button below to your bookmarks bar. Then, while viewing any merit badge page on scouting.org, click it to import the badge instantly — no file saving needed.

⚜ Save Merit Badge ← drag to your bookmarks bar
  1. Go to scouting.org → Merit Badges and open the page for the badge you want.
  2. Save the page as HTML:
    Mac — ⌘S → choose Webpage, HTML Only
    Windows — Ctrl+S → choose Webpage, HTML only
  3. Upload the saved .html file below.
